## First minute
标题页写着怎么操作，按回车开始。第一学期“大一上”只有左边掉作业本，掉得慢，我左右跑着接，每接到一本分数就在原地跳出来，连着接倍数往上涨。蜡烛一直在慢慢变短，中间飘下来一个枕头，接住蜡烛就长回来一截。大约二十五秒后屏幕中间出现“大一下 · 第一份实习”，右边开始掉工单，右上角多出一条实习条。这时第一次出现左边一本作业、右边一张工单同时落地的局面，我只能接一头，漏掉的那头条子掉一格：这就是这个游戏。

## Challenge
第一次真正的麻烦在第 50 到 80 秒，“大二上”：下落变快，天上开始掉手机，接到会愣住一秒多。到“大二下”红色告警铃出现，它比别的都快，漏掉一次实习条掉一大截。学业条、实习条任意一条见底，或者蜡烛烧完，这一局就结束，从大一上重来。最后一学期“大三上”最快最密，不放弃一些东西是撑不下来的。 *(provisional)*

## Core loop
- 左右跑，接住落下来的作业和工单；接到加分、涨倍数、对应的条回一点。
- 漏掉的东西让对应的条掉一截，倍数清零；蜡烛一直在烧，要抽空接枕头。
- 每个学期更快更密，多一种新东西；撑过五个学期，走进“续签”或“回学校”的门，看结局和分数。
- 输了或通关后一个键重来，最高分留着。

## Goal & fail state
- 目标：从大一上撑到大三上结束，然后在两扇门里选一扇；分数越高越好，最高分跨次保留。
- 失败：学业条或实习条见底，或蜡烛烧完，本局结束，按 R 从头再来。

## Features
- [ ] 左右移动和冲刺，按键当帧生效，接物判定比画面略宽、手机判定比画面略窄
- [ ] 六种掉落物，各有自己的轮廓和效果：作业本、工单、告警铃、奖杯、枕头、手机
- [ ] 学业条、实习条和两头烧的蜡烛，蜡烛低于四分之一时人变慢
- [ ] 五个学期一个比一个快，屏幕上显示当前学期，每学期开头有一行字说明多了什么
- [ ] 分数在接到的位置跳出来，连续接到涨倍数，倍数显示在分数旁边
- [ ] 最高分保存在本机，结算页说明有没有破纪录
- [ ] 通关时走进“续签”或“回学校”的门，各有一句结局
- [ ] 标题、暂停、失败、结算四个画面，声音可静音
